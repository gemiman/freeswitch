# 海外呼叫中心系统详细设计文档

## 1. 系统概述

本方案旨在建立一个低延迟、高可用的海外呼叫中心。
*   **PSTN 落地**: 阿里云国际版语音服务 (Direct Route / SIP Trunk)。
*   **核心交换**: FreeSWITCH (部署于海外节点，如香港、新加坡或法兰克福，建议与阿里云 SIP 接入点同区域)。
*   **坐席终端**: 自研 WebRTC 网页软电话 (无需安装插件)。
*   **业务系统**: 负责坐席管理、话单统计、ACD (自动呼叫分配) 逻辑。

## 2. 网络拓扑架构

```mermaid
graph TD
    User[海外用户 (PSTN/Mobile)] -->|SIP/RTP| Aliyun[阿里云国际语音网关]
    Aliyun -->|SIP Trunk (UDP/5080)| FS[FreeSWITCH Server]
    
    subgraph "企业内网 / 办公区"
        Agent[WebRTC 坐席浏览器] -->|SIP over WSS (TCP/7443)| FS
        Agent -->|HTTPS| Biz[自建业务管理平台]
    end
    
    Biz -->|ESL (Inbound/Outbound)| FS
    FS -->|CDR/Events| DB[(数据库/Redis)]
```

## 3. 关键技术点

### 3.1 阿里云 SIP Trunk 对接
*   **鉴权方式**: IP 白名单模式（推荐）或 用户名/密码摘要认证。
*   **编码**: 优先 G.711 (PCMU/PCMA)，其次 G.729。
*   **网络**: 必须确保 FS 服务器与阿里云 SIP 接入点的网络延迟 < 100ms，丢包率 < 1%。

### 3.2 WebRTC 坐席接入
*   **协议**: SIP over WebSocket (WSS)。
*   **加密**: TLS 1.2/1.3 必须开启，RTP 必须使用 SRTP (DTLS)。
*   **NAT 穿透**: 必须配置 ICE/STUN/TURN 服务器（如 Coturn），解决坐席在内网无法建立 P2P 音频流的问题。

### 3.3 业务控制 (ESL)
*   **Inbound 模式**: 业务系统主动连接 FS，用于发送 `originate` (外呼)、`hangup` (挂断) 等指令。
*   **Outbound 模式**: 呼叫进入 Dialplan 后，FS 主动连接业务系统，用于复杂的 IVR 交互或 ACD 路由决策。

## 4. 呼叫流程设计

### 4.1 坐席外呼流程 (点击拨号)
1.  **发起**: 坐席在网页点击“拨号”。
2.  **指令**: 业务系统通过 ESL 向 FS 发送 `originate` 指令。
    *   先呼叫坐席: `user/1001`
    *   坐席接通后，桥接阿里云网关: `sofia/gateway/aliyun/0085212345678`
3.  **桥接**: FS 建立两条腿 (Leg A: WebRTC, Leg B: Aliyun)，并混合音频。

### 4.2 客户呼入流程 (Inbound)
1.  **进线**: 用户拨打阿里云提供的 DID 号码。
2.  **路由**: 阿里云将 SIP INVITE 转发至 FS `:5080` 端口。
3.  **分配**: FS 触发 Dialplan，通过 ESL 询问业务系统“分配给谁？”。
4.  **振铃**: 业务系统返回空闲坐席 `1001`，FS 执行 `bridge user/1001`。

## 5. 安全规范
1.  **ACL**: 仅允许阿里云 IP 段访问 `:5080`。
2.  **Fail2Ban**: 对 `:5060` 和 `:7443` 开启扫描防护。
3.  **RTP 端口**: 限制 UDP 16384-32768，并在防火墙放行。
