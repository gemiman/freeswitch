# 中国大陆呼叫中心系统详细设计文档

## 1. 系统概述

本方案针对中国大陆企业级呼叫中心场景设计。
*   **PSTN 接入**: 三大运营商 (电信/联通/移动) IMS 专线 或 数字中继网关。
*   **智能交互**: 集成中文 ASR (语音转文字) 和 TTS (文字转语音)，实现智能 IVR。
*   **部署环境**: 国内公有云 (阿里云/腾讯云) 或 本地机房 (私有云)。

## 3. 核心技术难点与解决方案

### 3.1 运营商 IMS 对接
国内运营商 IMS 线路通常有严格限制：
*   **鉴权**: 必须使用指定的 IP 地址，有时绑定 MAC 地址。
*   **协议兼容**:
    *   必须支持 `100rel` (PRACK) 可靠传输。
    *   必须定期发送 `OPTIONS` 心跳保活。
    *   `User-Agent` 常常需要伪装成特定设备 (如 `Huawei`, `ZTE`)。
*   **编码**: 强制使用 `PCMA` (G.711a) 或 `G.729`。

### 3.2 中文智能 IVR
*   **方案**: 使用 `mod_unimrcp` 对接阿里云或科大讯飞的 ASR/TTS 服务。
*   **流程**: 用户说话 -> FS 通过 MRCP 发送音频 -> ASR 识别为文本 -> 业务系统判断意图 -> TTS 合成回复音频。

### 3.3 国内 WebRTC 优化
*   国内跨运营商 (如电信宽带访问移动服务器) 丢包率高。
*   **优化**: 必须部署多线 BGP 机房的 Coturn (TURN Server) 中转媒体流。

## 4. 业务流程设计 (智能 IVR)

1.  **进线**: 用户呼入 `010-88888888`。
2.  **欢迎语**: 播放 "欢迎致电XX科技，请直接说出您的问题"。
3.  **ASR 识别**:
    *   用户说: "我想查一下我的快递到哪了"。
    *   ASR 返回文本: "查快递"。
4.  **意图识别**: 业务系统通过 ESL 收到文本，匹配到 [查询物流] 意图。
5.  **处理**: 业务系统调用快递 API 查询状态。
6.  **TTS 播报**: 合成语音 "您的快递正在派送中，快递员电话..." 并播放。

## 5. 安全合规
1.  **实名制**: 所有外呼主叫号码 (Caller ID) 必须在运营商备案，严禁更改为未备案号码。
2.  **录音留存**: 录音文件必须保存至少 6 个月（金融类业务要求更长）。
3.  **防骚扰**: 需对接“黑名单”系统，过滤高频骚扰投诉用户。
